# Writeup: reverse_cipher (picoCTF 2019 / Academy)

**Категория:** Reverse Engineering  
**Сложность:** Easy/Medium  
**Флаг:** `academy{r3v3rs3e2ac6361}`

---

## Анализ

Бинарник `rev` читает файл `flag.txt` и записывает зашифрованную версию в `rev_this`. 
С помощью Ghidra Headless анализа (команда `python3 main.py ghidra ./rev`) был получен псевдокод функции `main`, раскрывающий алгоритм:

1. **Байты 0-7**: Копируются без изменений (префикс `picoCTF{` или `academy{`).
2. **Байты 8-22**: 
   - Если индекс четный: `cipher = plain + 5`
   - Если индекс нечетный: `cipher = plain - 2`
3. **Байт 23 (последний)**: Копируется без изменений (символ `}`).

## Решение

Алгоритм полностью обратим. Мы читаем байты из `rev_this` и применяем обратные операции:
- Четный индекс: `plain = cipher - 5`
- Нечетный индекс: `plain = cipher + 2`

Скрипт `solve_reverse_cipher.py` автоматизирует этот процесс и мгновенно восстанавливает исходный флаг.
